# sMMC40M project website

This repository hosts the [sMMC40M website](https://xenali96.github.io/sMMC40M/).
The dataset, benchmark code, and release documentation are linked from the
[Zhang Lab repository](https://github.com/aicb-ZhangLabs/sMMC40M).

The site is built with MkDocs from `website/` and published by the Website
workflow. To preview it locally:

```bash
python -m pip install -r requirements-docs.txt
mkdocs serve
```
