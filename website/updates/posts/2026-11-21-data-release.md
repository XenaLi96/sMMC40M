# Dataset update adds 32 samples

Added 32 samples and 10,180,038 gene-positive cell and nucleus observations. The public release now contains 156 samples and 48,652,230 observations.

<!-- more -->

| Platform | Samples added | Observations added |
| --- | ---: | ---: |
| Visium HD | 5 | 269,023 |
| Xenium | 27 | 9,911,015 |
| **Total** | **32** | **10,180,038** |

Counts include cells or nuclei with at least one measured Gene Expression count. The dataset now includes 58 Visium HD and 98 Xenium acquisitions. The original benchmark splits still refer to their frozen cohort.

See the [public Hugging Face release](https://huggingface.co/datasets/zhang-lab/sMCC40M/tree/7c0d215a4683e6f074177e708a192c416e2e2708) for the updated sample index, cell-type summaries, source terms and checksum manifests.
